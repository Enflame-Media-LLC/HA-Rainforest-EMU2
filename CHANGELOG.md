# Changelog

## 0.1.1

- Initial HACS custom integration for Rainforest Automation EMU-2 and legacy
  RAVEn USB energy monitors.
- Adds bounded serial setup and polling, full-cycle recovery, exact USB path
  repair, safe built-in migration, and transactional reconfiguration.
- Adds power, delivered energy, received energy, price, signal-strength sensors,
  and privacy-safe diagnostics.
- Allows the four-second response window documented by Rainforest's EMU-2 serial
  API and records privacy-safe setup failure stages in the Home Assistant log.
